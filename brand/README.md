# Levuche brand kit

- `rollout-checklist.md`: putting levuche.com live everywhere
- `guide/`: one-page brand guide (PDF, PNG, SVG)
- `logo/`: icon, full logo, on-dark logo, wordmark and glyph (SVG and PNG)
- `favicon/`: favicon set, web manifest and the `<head>` snippet
- `social/`: share image 1200x630, square 1080, avatar 400
- `fonts/`: Sora (Open Font License)

Built from the approved Levuche design canvas (tokens v1.0, 25 November 2026). Levuche is a product managed by Jagodana LLC.
